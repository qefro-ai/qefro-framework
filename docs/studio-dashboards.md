# Studio dashboards

Dashboard Studio configures `DashboardDef` cards (`metric`, `table`, `chart`, `list`). Each card references an existing entity (and optional field/filters). Cards are evaluated with the same `dashboard_card_value` path as the business dashboard.

Print format Studio edits `PrintFormat` (header, items table, totals, footer) and previews HTML through the existing print renderer. It is not a Canva-style designer.
